# Third-party reference

Astra's production workflow is informed by the public OpenAI Hatch Pet Skill and Codex pet contract:

- canonical character/base as visual source of truth
- state-specific generation grounded on the canonical base
- fixed cell geometry
- deterministic atlas assembly
- contact-sheet and motion-preview QA
- rejection of identity drift and extraction artifacts
