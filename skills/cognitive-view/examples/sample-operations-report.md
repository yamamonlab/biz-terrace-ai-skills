# 物流センター 出荷遅延についての月次報告（架空）

10月の運営会議向けの報告です。数値はすべて各センターからの月次報告によるもので、本社側で再集計はしていません。

全センター合計の出荷遅延率は、5月が4.1%、6月が3.8%、7月が5.2%、8月が7.9%、9月が8.4%でした。10月は速報値で6.1%です。7月から悪化し、9月がこれまでで最も高く、10月にやや戻っています。遅延率は、約束した出荷日を1日以上過ぎた件数を出荷件数で割った値です。

センター別に見ると、9月の出荷件数は東センターが41,200件、西センターが28,500件、南センターが19,800件でした。9月の遅延率は東センターが11.2%、西センターが6.3%、南センターが5.1%です。10月のセンター別の数値は、東センターが7.4%、西センターが5.0%と報告されていますが、南センターはまだ報告が届いていません。

遅延の原因として、報告では2つが挙がっています。1つ目は、東センターで7月に行った倉庫管理システムの移行です。移行後、ピッキングリストの出力が1回あたり平均40分遅れるようになり、その日の出荷便に間に合わない注文が出ました。つまり、システム移行がピッキングリストの遅れを生み、それが出荷の遅れにつながったという流れです。2つ目は、8月以降の夜間シフトの欠員で、東センターと西センターで起きています。この2つは別々の原因として報告されており、どちらがどれだけ遅延に効いたかは分けて測れていません。

10月に東センターの遅延率が下がったのは、9月末にピッキングリストの出力を1日2回から4回に増やしたためだと東センターは説明しています。ただし、本社の物流企画部は、10月は出荷件数そのものが少ない月なので、改善したと判断するのは早いという立場です。この点はまだ結論が出ていません。

南センターは、システム移行も欠員もなかったため遅延率は低いままですが、5月から10月まで一度も5%を大きく下回っていない点は、別の課題として残っています。

未解決の点が3つあります。1つ目は、夜間シフトの欠員をいつまでに埋めるかで、人事部が11月中に採用計画を出すことになっています。2つ目は、システム移行の影響を元に戻すための追加改修をするかどうかで、担当はまだ決まっていません。3つ目は、南センターの10月の遅延率で、報告が届き次第共有します。

次回の運営会議では、10月の確定値を見たうえで、追加改修の要否を判断する予定です。
