# Design — なぜ v2 はこの形なのか

実行時には読まない。規則を足す・削る前に読む。

## 目的

大量の文書を、**情報量を落とさずに** 人間が短時間で理解できる形にする。認知負荷の言葉で言えば、題材そのものの負荷（intrinsic）は保ち、提示の仕方に由来する負荷（extraneous）だけを減らす（Sweller, 2010）。要約して短くするのは intrinsic を削る操作なので、このSkillの仕事ではない。

## v1 から前提を変えた理由

v1 は「どう見せるか」の規則（表現の階層、面積比、予算表、図とグラフのゲート）を積み増した。2026-09-23 に、当日配布版（78ce777）を9条件で実際に生成させたところ:

- **形は崩れなかった**: 9本すべてが完結した単一HTML、外部依存なし、狭い画面で崩れない
- **中身が崩れた**: 弱いモデルでは3本中3本、中程度では4本中2本に、原文に無い数値計算（`1,100円 × 250名 × 12か月` = 330万円）、単位の取り違え（月額を年額と表記）、無い年号、無い担当、テンプレート由来の「循環」が入った。強いモデルは0本
- 原因は3つあった
  1. **忠実さの規則が、表現の規則の中に埋もれていた。** 27KBの SKILL.md のうち、捏造禁止は数か所の注意書きだった
  2. **テンプレートが配布サンプルと同じ題材で書かれ、原文に無い数値・担当・因果を含んでいた。** モデルはそれを写した
  3. **重すぎた。** 実行時に読むファイルは149KB。チャットAI向けの4本には図の規則が入っておらず、生成した3モデルが独立に「読めと言われたが渡されていない」と報告した

## v2 の設計判断

| 判断 | 理由 |
|---|---|
| **事実台帳を最初の手順にし、全要素に台帳番号を付ける** | 忠実さを「気をつける」ではなく、作業の順序で強制する。台帳の引用は原文にそのまま存在するかを機械で照合できる |
| **禁止事項を「計算・単位・担当/日付・因果・評価語・発言者」の6つに具体化** | 実測で起きた捏造をそのまま型にした。抽象的な「原文にない情報を足さない」だけでは弱いモデルに届かなかった |
| **部品は `{{…}}` の骨組みだけ。見本の中身を書かない** | テンプレートの文言がそのまま出力に写ることを実測した |
| **実行時のファイルを2つ（SKILL.md + components.md）に** | チャットAIへ渡す本数を減らし、「読めと言われたが無い」状態をなくす |
| **表現の振り分けを優先順位付きの1表に** | v1 は比較・数量・時系列の条件が複数ファイルで食い違い、数値は実質的に常に表へ流れていた |
| **タイムライン・流れ図・棒グラフを HTML/CSS で組む** | SVGは幅に合わせて縮み、360px 幅で文字が約4pxになった。HTMLは折り返すので読める |
| **アニメーションは順序・推移・因果にだけ、1回、`prefers-reduced-motion` で止まる** | 動きは注意を引く。順序を示す時は理解を助けるが、装飾の動きは余計な負荷になる（coherence 原理） |
| **原文を詳細層にまるごと貼らない** | v1 の見本は原文を畳んで貼り、保持率を100%に見せつつ、構造層には7割しか出していなかった。台帳の引用が裏付けを兼ねる |
| **出力の自己採点を返信に書かせない** | 採点表やBriefを返信に出すと出力が長くなり、無料枠で途中で切れる |

## 残したもの

- 5秒 / 構造 / 詳細の3層（Shneiderman, 1996 の "Overview first, zoom and filter, then details-on-demand"。秒数は本Skillの運用上の目安で、Shneiderman の主張ではない）
- 見出しを読者の問いにすること（signaling）
- 状態記号を5つに限ること（signaling の過剰を避ける）
- 比較表の狭い画面でのカード化、印刷で詳細層を開く規則

## 出典

- Sweller, J. (2010). Element interactivity and intrinsic, extraneous, and germane cognitive load. *Educational Psychology Review*, 22, 123–138.
- Shneiderman, B. (1996). The eyes have it: A task by data type taxonomy for information visualizations. *Proceedings of the IEEE Symposium on Visual Languages*.
- Mayer, R. E., & Fiorella, L. (2014). Principles for reducing extraneous processing in multimedia learning. In *The Cambridge Handbook of Multimedia Learning* (2nd ed.). coherence 原理は23件中23件の実験で支持、効果量の中央値 0.86。

## 規則を足す・削る時

- 足す前に、それが **実測した失敗** に対応しているかを確認する。想像上の失敗のために規則を足さない
- 1つの入力の見た目を良くするための規則を、核（SKILL.md）に入れない
- 削る時・変える時は `docs/eval-protocol.md` の手順で、弱いモデルを含めて測る
