## 追記: 記事型への変更後（同日）

ダッシュボード型の出力は、本文の割合が8%で、6章中3章に段落が無かった。記事型（文章が主役、図表は要所だけ）に変えたうえで、同じ条件で7本を生成した。

| 項目 | 結果 |
|---|---|
| 本文の割合 | 47〜64%（ダッシュボード型は8%） |
| 図表だけの章 | 0/7 |
| 数値が主役の入力で、推移を折れ線にした | 3/4 |
| 中程度・強いモデルの捏造 | 0/3 |
| 弱いモデル | 4/4 に何らかの逸脱 |

**文章を書かせると、弱いモデルは書き手として推測を書く**（「〜と考えられます」「〜の可能性がある」）。差や倍率の計算（「約2ポイント」「2倍」）、原文に無い特徴、言い換えた引用も出た。禁止事項（7つ目）を足しても、弱いモデルでは 2/2 本で残った。

`scripts/check-output.mjs` は、これらをすべて ERROR として検出した。**弱いモデルで使う時は、出力を照合するか、読者が「原文との対応」で確かめる前提にする。**
