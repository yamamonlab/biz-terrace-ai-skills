## 使い方

SKILL.md の既定見出し（今どこにいるか / 何で止まっているか / 何が分かれば動くか / 知らなくていい詳細）は、**停滞している検討資料**に最適化されている。入力がそれ以外のジャンルなら、ここから問いを差し替える。

**差し替えても変わらない原則**:

- 見出しは **読者の問いへの答え** の形であること。資料の章名の写しは不合格
- 5秒層の見出しは **主題＋現在の状態** の2要素
- `UNDERSTAND` の境界（推奨・優先順位を出さない）はジャンルに関わらず不変
- 詳細層に入れてよいのは原文引用と経緯の細部だけ

## 1. ジャンル判定

Semantic Map（SKILL.md §2）で付けた種別の分布から引く。**最初に当たったものを採る。**

| 分布の特徴 | ジャンル |
|---|---|
| 未解決・制約が多く、時間軸上で止まっている | **停滞検討**（既定） |
| 事象の発生時刻と影響範囲があり、再発防止の記述がある | **障害・インシデント** |
| 複数の対象が同じ軸で並び、選定・採否が論点 | **比較検討** |
| 手順・条件・例外が主で、対象読者に「守らせる」意図がある | **規程・手順** |
| 主張と根拠の対で構成され、時間軸を持たない | **調査・論考** |
| 発言者と発言内容の対が大半を占め、決定が点在する | **議事・打ち合わせ** |
| 期間内の数値推移と、その解釈がある | **定例報告** |

複数に当てはまる時は、**comprehension_goal に最も効く1つ**を選ぶ。混ぜない。

## 2. ジャンル別の問い見出し

各行が構造層の `<h2>` になる。3〜4本で足りない資料は、塊を増やすのであって見出しを増やさない。

### 停滞検討（既定）

1. 今どこにいるか
2. 何で止まっているか
3. 何が分かれば動くか

### 障害・インシデント

1. 何が起きたか
2. なぜ広がったか
3. 再発を止める条件は何か

時系列の間隔が意味を持つので、timeline 図が背骨になりやすい唯一のジャンル。ただし3文テストは同じく掛ける。

### 比較検討

1. 何を選ぼうとしているか
2. 何がどう違うか
3. まだ比べられていないことは何か

**比較表が背骨になる。** `UNDERSTAND` では、原文にないスコア・重み・総合評価を作らない。3本目の見出しが `DECIDE` への入口になる（`references/decide-contract.md`）。

### 規程・手順

1. 誰が何をすることになっているか
2. どこに例外があるか
3. 判断が要るのはどこか

**「守らせる」意図のある文書なので、原文の条件を落とすと実害が出る。** 情報保持率の目標を 95% ではなく **98%** で運用する。例外・但し書きは1つも落とさない。

### 調査・論考

1. 何を主張しているか
2. 根拠はどこまで示されているか
3. 示されていないことは何か

時間軸がないので timeline を使わない。**Evidence の帰属（誰の主張か）が最も重要なジャンル**で、2本目の見出しがその受け皿になる。

### 議事・打ち合わせ

1. 何が決まったか
2. 何が決まっていないか
3. 次に誰が何をするか（**原文に記述がある場合のみ**）

3本目は原文に担当・期限の記述がある時だけ置く。無いなら「原文に次の手順の記述なし」と1行書く。**ここで担当を推定して埋めるのは `UNDERSTAND` 違反。**

### 定例報告

1. 数値はどう動いたか
2. その動きを何で説明しているか
3. 説明がついていない部分はどこか

**メトリクスカードが最も自然に成立するジャンル。** ただし2本目で「解釈は誰のものか」を帰属させる。数値と解釈を同じカードに混ぜない。

## 3. どれにも当てはまらない時

1. SKILL.md の Routing Reminder を再確認する。原文の流れを保ちたい、単図を納品したい、といった場合は本 Skill の対象外
2. 対象内だが表に無いジャンルなら、**既定（停滞検討）ではなく、comprehension_goal から問いを3本自作する**。「今どうなっているか」「何が効いているか」「何が分かっていないか」が最も汎用の骨格
3. 自作した問いは Comprehension Brief に記録する

## 4. ジャンルを足す時

新しい行を足す条件は2つ。

- **既存の問いでは答えの形にならない**こと（既存ジャンルの言い換えでない）
- `references/eval-protocol.md` の理解到達テストを、そのジャンルの実入力で1回通していること

ジャンルを増やすほど判定が曖昧になるので、**表は7行前後を上限の目安**とする。
