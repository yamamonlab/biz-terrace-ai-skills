# Part（全体に対する構成比）

## 使う条件

- **全体が原文に明示されている**（合計、総数、母数）
- その内訳が **2〜5項目** で、**構成比そのもの** が論点
- 合計が原文に無いなら **使わない**。足し上げて母数を作るのは原文にない数値の生成にあたる

## 型の選択

| 条件 | 型 |
|---|---|
| 内訳が2〜3項目、または「大半が1つ」を示したい | **積み上げ横バー1本** |
| 内訳が4〜5項目で、互いの比較もしたい | **積み上げ横バー**（ドーナツより読み取りが速い） |
| ドーナツ | 原則使わない。角度の比較は長さより遅い |

**既定は積み上げ横バー1本。** ドーナツは、原文が円グラフで提示していて再現が要る時だけ。

## レイアウト規則

- 1本の横バーを100%とし、内訳を左から大きい順に並べる
- 各区画に**ラベルと値を直接**置く。区画が狭くて入らないなら、その項目は「その他」へまとめず**引き出し線**で外に出す
- 色は1系統の濃淡。カテゴリごとに色相を変えない
- 「原文に記述なし」の残余がある場合、**斜線パターンの区画**として明示する。黙って100%に丸めない

## Anti-pattern

- 合計が原文に無いのに構成比を描く
- 端数処理で合計を100%に合わせ、丸めたことを書かない
- 6項目以上を1本に詰める
