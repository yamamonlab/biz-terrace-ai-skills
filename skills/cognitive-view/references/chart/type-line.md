# Line（時間に沿った推移）

## 使う条件

- 同じ指標の値が **3時点以上** ある
- **推移の向きや変化の速さ** が論点（上がった / 落ちた / 横ばい）
- 時点が3つ未満、または各時点で指標が違うなら **Line にしない**（Bar か表）

**時点が並ぶだけで指標が無いものは Timeline（`references/diagram/type-timeline.md`）であって Line ではない。** Line は縦軸に量を取る。

## レイアウト規則

- **y 軸は 0 起点。** 変化を強調するために途中から始めない
- 系列 ≤ 3。2つ以下なら凡例ではなく**線の端にラベル**を置く
- 点は**実測のある時点だけ**に打つ。補間した点にマーカーを置かない
- 始点と終点の値ラベルは必ず置く。中間は論点のある点だけ
- 急変のある区間だけ accent。全体を色付けしない

## 不確認区間

- 原文に値が無い区間は **破線** でつなぎ、「原文に記述なし」と注記する
- 推定で線を引かない。点が2つしか無いなら線を引かず、2点のままにする

## Anti-pattern

- y 軸を途中から始めて変化を誇張する
- 実測が2点なのに滑らかな曲線を引く
- 時点間隔が不均等なのに等間隔で並べる（日付を x 位置に反映させる）
