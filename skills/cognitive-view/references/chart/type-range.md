# Range（幅のある値・確定していない値）

## 使う条件

- 値が **点ではなく幅** で語られている（「3か月程度」「2〜3社」「初年度は最高、2年目以降は最安」）
- **確定していないこと自体** が論点
- 幅の根拠（見積もり、1件の事例、口頭説明）が原文にある

**このSkillで最も使い道のある型。** 未確認・見込み・条件付きの値を、点に潰さずに描ける唯一の型である。点で描くと「確定した値」に見えてしまい、情報が反転する。

## レイアウト規則

- 横軸に値を取り、**幅を帯**で描く。中央値の点を打たない（原文に中央値が無いなら作らない）
- 帯は **破線の枠 + 薄い塗り**。実線の帯は「確定した幅」にだけ使う
- 帯の端に**下限と上限の値ラベル**を置く
- **根拠の強さを帯の下に1行で書く**（「事例1件」「口頭説明のみ」「見積書あり」）
- 確定値と並べる時、確定値は**実線の細い縦線**にして帯と形で区別する

## 条件で反転する値

「初年度は最も高いが、2年目以降は最も安い」のように**条件で順位が入れ替わる値**は、Bar で1つの値として描かない。Range か、条件ごとに分けた2本の Bar にする。**片方だけ描くと原文の意味が反転する。**

## Anti-pattern

- 幅の中央を点で描き、幅を消す
- 破線と実線を混ぜたまま、何が破線かをラベルで書かない
- 根拠の強さを書かずに幅だけ描く（読者が「調査済みの幅」と誤読する）
