# 社内AIツール導入検討メモ（架空）

第3回定例の議事メモです。前回からの引き継ぎ分も混ざっています。そもそもの発端は5月の業務改善アンケートで、資料作成と議事録まとめに週あたり平均6.2時間かかっているという回答が出たことでした。このとき情報システム部から「まず現状把握を先にすべきでは」という意見があり、6月はヒアリングだけで終わっています。ヒアリング対象は営業部12名、管理部8名、開発部5名。ここで出てきた困りごとは、資料作成そのものより「前任者が何を検討したのか分からない」という話が多かったです。7月に候補ツールの一次選定を行い、3つに絞りました。8月に部分トライアルを実施し、今回がその報告という流れになります。

候補の1つ目はアルファ社のものです。月額は1ユーザー2,400円で、今の想定人数だと年間およそ720万円。機能面では一番広く、社内文書の検索と要約が両方できます。ただし社内データを外部に置く構成が前提になっていて、法務からは「契約書の雛形を扱う部署では使えない」という指摘が出ました。2つ目はブリッジ社で、月額1,100円と安いのですが、できることが要約に寄っています。データは国内に置けます。3つ目のコンパス社は、社内サーバーに入れる形なので外に出ません。ただし初期構築で3か月と、担当エンジニア1名の専任が必要という見積もりでした。金額は初年度が一番高く、2年目以降は逆に一番安くなります。

なお7月の一次選定のとき、実はもう2社ほど候補に挙がっていました。片方は資料作成に特化していて要約が弱く、もう片方は日本語の扱いが不安定だという評価でヒアリング段階で落としています。この2社を落とした理由が議事に残っていないという指摘が今回あり、これは記録として補足しておくべきという話になりました。前任者が何を検討したか分からない、という6月のヒアリング結果と同じことを、自分たちが繰り返していることになります。

セキュリティの観点では、法務と情報システム部の見解が割れています。法務は「外部保管そのものが問題」という立場、情報システム部は「暗号化と監査ログがあれば運用でカバーできる」という立場です。この点はまだ決着していません。決着していないまま費用の比較だけが進んでいる、という状態が続いています。管理部からは、そもそもセキュリティ要件を先に確定させてから候補を絞るべきだったのではないか、という意見も出ました。順番が逆になっているという指摘です。

8月のトライアルで分かったことの方が重要かもしれません。営業部に2週間使ってもらったのですが、最初の3日で利用が9割落ちました。理由を聞くと、出力が長すぎて結局読んでいない、という声が最も多かったです。次に多かったのが、どこまで信じていいか分からないので結局元資料を開き直す、というもの。つまり時間が減っていない。ここから見えてきたのは、ツールを入れるだけでは使われないということで、出力の形を決めておかないと現場は読まない、というのが今回の一番の学びだと思います。対策としては、部署ごとに「こういう形で出す」というルールを先に決めてから配る、という案が出ています。ただしこれを誰が決めるのかは決まっていません。

未確認のままの点が3つあります。1つ目は、コンパス社の3か月という構築期間が、他社の同規模事例でも同じなのかを確認できていないこと。ヒアリングした事例は1件だけです。2つ目は、ブリッジ社のデータ保管場所について、契約書の文面をまだ法務が読んでいないこと。営業担当者の口頭説明しか根拠がありません。3つ目は、想定人数の250名という数字が、実際に使う人数なのか、アカウントを配る人数なのかが部署間でずれていることです。営業部は「全員に配る」、管理部は「希望者のみ」と理解していました。この前提が違うと費用の比較そのものが崩れます。

それから、これは議題外でしたが、トライアルに参加しなかった開発部から「自分たちはすでに別の手段で似たことをやっている」という話が出ています。全社で1つに揃えるのか、部署ごとに違ってもよいのかという方針が決まっていません。ここも本来は先に決めるべき論点だったと思います。

次回までの宿題として、法務による契約書確認、想定人数の定義統一、それから出力ルールの担当決めの3つが挙がりました。判断は次々回を目標にしていますが、前提の確認が終わらなければ延びると思います。
