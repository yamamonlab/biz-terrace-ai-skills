# Concept Direction Template

Concept Gateでユーザーへ提示する方向性の出力契約。画像生成前に、イベントの主張の違いを比較できる形で出す。参照画像は任意で、提示された場合だけ役割別に記録する。

## Candidate count

- 通常は3〜5案。
- 主張が固まっている場合は3案、探索余地が大きい場合は5案。
- ユーザーが方向性を指定済みなら、指定案の精緻化を1案だけ返す。

## Required candidate fields

```markdown
### A｜{方向性の短い名称}（発想レンズ：{Transformation / Business Outcome / Timely Question / Workflow / Community Mission}、おすすめ順位：{n}）

**メインコピー**

> {承認済み、または仮案であることを明示した主コピー}

**小さく入れる情報**

> {イベント名／日時／形式／主催名など、確定しているものだけ}

**文字をアート化する考え方**

- {意味の中心となる語・対比・問い}
- {変形、接続、方向、反復、分割、余白などへの翻訳}

**ビジュアル**

- 構図：{主役の位置、視線の流れ、余白}
- 配色：{背景、主文字、補助色}
- 要素：{線、円、点、記号、質感。必要なものだけ}
- 情報密度：{low / medium / high と理由}

**この案が伝えること**

{イベントのどの価値を最も早く伝えるか}

**向いている場合／トレードオフ**

{優先する認知効果と、弱くなる要素}

**推薦理由**

{目的、対象者、可読性、文字アートの余地、差別化、必要情報との共存}
```

## Direction lenses

案の差は背景色ではなく、イベントの主張と文字アートの文法で作る。候補として次のレンズを使えるが、イベント内容に合うものだけを選ぶ。

| レンズ | 主役にするもの | 文字アートの起点 |
| --- | --- | --- |
| `Transformation` | 参加前から参加後への変化 | 対比、変形、移動、連続 |
| `Business Outcome` | 判断、成果、仕事への価値 | 根拠、到達、重心、強調 |
| `Timely Question` | なぜ今学ぶのかという問い | 問い、空白、反復、視線 |
| `Workflow` | 調査・整理・伝達などの流れ | 接続、順序、カード、線 |
| `Community Mission` | 越境、共創、主催者の思想 | 交差、重なり、ネットワーク |

## Gate rules

- 方向性案の提示中は画像生成を実行しない。
- 「アート風」は特定の質感を意味しない。黒板、チョーク、紙、ネオンなどは明示された場合だけ採用する。
- 未確認の料金、URL、日付、機能、固有名詞は空欄または掲載対象外にする。
- 機能一覧や長い告知本文をサムネイルの小情報へ詰め込まない。
- ユーザーの選択後に、選択案をProduction Briefへ固定する。
