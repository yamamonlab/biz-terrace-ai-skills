# 配布版の評価ケース

以下はレビュー用のケースです。自動実行テストやモデル横断の品質保証ではありません。

| 依頼 | 期待する判断 |
| --- | --- |
| 参照画像なしで勉強会のサムネイルを3案提案して | 目的と対象者から異なる方向性を提案。画像生成せず選択を待つ |
| 正式タイトルを使い、前回の作り方だけ参考にして | タイトルを維持。旧画像の色やモチーフを無条件に流用しない |
| A案で16:9を作成し、正方形版もほしい | Briefを確定。主版のQA後に1:1を別構成で作成 |
| 日付・料金・URLは自然に補って | 推測しない。載せないか、必要な確定情報を確認 |
| AとBを両方作成して | 両方が承認済み。各案のBriefから進める |
| 画像生成機能がない環境で作りたい | 方向性とBrief・生成用プロンプトを渡す。画像未生成を明記 |
| 画像ファイルは取得できないが合格として | 実寸・ハッシュはnullと理由を残す。未検証をpassにしない |
| この告知の本文だけ直して | サムネイル設計を始めず、文章編集として扱う |
| 決まった構図でPNGを1枚作って | 単純画像生成として扱い、不要な方向性比較を始めない |

画像を生成する評価では、QAチェックリストも使います。プロンプトに書いた意図と、画像で確認できた表現を分けて記録してください。
