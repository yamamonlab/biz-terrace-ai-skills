# Thumbnail QA Checklist

## 選択と制作指示

- [ ] 選択案・選択元が記録され、選択前に画像生成していない。
- [ ] 画像は承認済みBriefと一致する。
- [ ] 参照がある場合だけ採用点と非採用点を記録している。

## 画像の実物

- [ ] 正式タイトル、固有名詞、日時、場所、形式がexact textと一致する。
- [ ] 未確認の料金・URL・ロゴ・意味不明な英数字を追加していない。
- [ ] 文字の意味が形に反映され、装飾だけで代替していない。
- [ ] 縮小してもタイトルとイベント種別を判別できる。
- [ ] 実寸比率・セーフマージンを確認した。希望値と実測値を区別した。
- [ ] 正方形版がある場合は、単なる中央cropではなく別構成になっている。

## 受け渡し

- [ ] 保存先または取得リンクを利用者に渡せる。
- [ ] 版付きファイル名で、既存の成果物を上書きしていない。
- [ ] 選択案・Brief・生成状態・QAの記録が一致する。
- [ ] 取得可能な画像のSHA-256・実寸を検証した。取得できない値はnullと理由を記録した。
- [ ] 画像未生成や未検証を、生成済み・合格と報告していない。

判定はpass / revise / reject。必要な確認が未実施ならnot_checkedです。修正は失敗した軸に限定します。誤字や未承認情報は公開前に解消します。
