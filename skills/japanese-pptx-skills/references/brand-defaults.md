# Default Brand Tokens
ユーザー指定およびselected themeがない場合のみ使用する。

このファイルは**具体値のfallback**であり、デザイン原則は `DESIGN.md` を正本とする。

## Surface
- Background: white
- Primary emphasis: default consulting blue
- Text: near-black / dark neutral
- Secondary: gray scale
- Warning: muted amber or equivalent,必要時のみ

具体的な色コードは制作環境に合わせて定義してよいが、資料内で固定する。

## Typography
- 日本語本文：環境で利用可能な可読性の高いサンセリフ
- Latin / number：本文フォントと調和するもの
- 同一資料内でfont familyを増やしすぎない

## Semantic defaults
- Primary: 選択対象、現在地、推奨案、最重要差分
- Dark text: 通常本文
- Gray: 過去、非重点、比較基準、補助
- Outline/white: 計画、未確定、外部前提等
- Actual: solid
- Forecast: dashed
- Estimate marker: `†`

Semantic meaningは色だけで表現しない。
