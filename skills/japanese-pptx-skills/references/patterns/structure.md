# Pattern family: structure

## 41 レイヤーマップ
- use_when: 複数層×系列の構造と自社の到達範囲を示す。
- proof_mechanism: 縦層×横系列の格子で空白と被覆を見せる。
- invariants: 自社リーチをブラケットで定量化。

## 42 バリューチェーン地図
- use_when: 工程、成功要因、プレイヤー被覆の空白を示す。
- proof_mechanism: 上中下の垂直対応で、誰がどこを覆うかを示す。
- invariants: 上=工程、中=成功要因、下=プレイヤー被覆幅。空白が主張。

## 43 組織マッピング
- use_when: 組織の類型や配置を地図化し、選択論点を示す。
- proof_mechanism: 組織図上の番号バッジで類型を位置づける。
- invariants: 下部に選択論点を対で置く。

## 44 全体と拡大
- use_when: 全体構造を維持しながら1領域を詳述する。
- proof_mechanism: 左の全体と右の拡大を引き出し線で接続する。
- invariants: 破線の引き出しで繋ぐ。

## 48 関係者相関マップ
- use_when: 主役を中心に複数関係者とモノ・金・データの関係を示す。
- proof_mechanism: 中央からの関係線種で交換内容を区別する。
- invariants: モノ=実線、金=破線、データ=点線。
